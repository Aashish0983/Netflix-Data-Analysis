# Netflix-Data-Analysis
SQL-based Netflix Data Analysis project using MySQL to analyze customer behavior, viewing history, subscriptions, content, devices, payments, and revenue through 15 real-world business queries.

# 🎬 Netflix Data Analysis – SQL Project

## 📌 Project Overview

This project focuses on analyzing a Netflix database using **MySQL**.

The database contains information about customers, profiles, content, viewing history, subscriptions, plans, devices, payments, and preferred languages.

The project uses SQL queries to solve real-world business problems and generate meaningful insights from customer and viewing data.

## 🎯 Project Objective

The main objective of this project is to:

- Analyze customer viewing behavior
- Identify popular movies and genres
- Analyze subscription plans
- Understand device usage
- Compare movies and TV shows
- Analyze customer language preferences
- Study content access patterns
- Analyze revenue by city
- Understand customer and profile behavior

## 🗂️ Database Tables

The database contains tables related to:

- `customers` – Customer information
- `profiles` – Customer profiles
- `content` – Movies and TV shows
- `viewinghistory` – Customer viewing history
- `plans` – Subscription plan details
- `subscribes` – Customer subscriptions
- `devices` – Device information
- `uses` – Profile device usage
- `childacc` – Child account information
- `adultacc` – Adult account information
- `customerslanguagepreferred` – Customer language preferences
- `paymentmethod` – Customer payment details
- `paymenthistory` – Payment and revenue information

## 🔍 Key Business Questions

Some of the major questions solved in this project:

1. Find the top 3 most-watched movies based on viewing hours.
2. Find the top genre in each category using the RANK function.
3. Find the number of subscribers for each plan.
4. Identify the most commonly used device type.
5. Compare average viewing time of movies and TV shows.
6. Identify the most preferred customer language.
7. Compare adult and child accounts.
8. Calculate the average number of profiles per customer.
9. Identify content with the lowest average viewing time.
10. Find the count of each content type.
11. Compare customers with unlimited and non-unlimited access.
12. Calculate the average monthly price of unlimited-access plans.
13. Find customers whose plans expire in 2028 or later.
14. Calculate and rank average revenue by city.
15. Find the most frequently viewed genre among adults for each category.
